# AGENTS.md

Guidance for AI coding agents working in this repository. Humans should start with [README.md](README.md).

## What this is

Mossad is a macOS menu bar app (Swift 6, SwiftUI with AppKit, macOS 26+). It detects Zoom, Google Meet, and Microsoft Teams calls, records two audio tracks (the user's mic and the call app's audio), and after the call it transcribes, identifies speakers by voice, summarizes, and writes one Markdown note per call to `~/Mossad/Meetings`.

The product goal is zero interaction. Any change that adds a click, a prompt, or a notification needs a strong reason.

## Build and test

```sh
cd Packages/MossadCore && swift test          # unit tests, no network
scripts/build.sh --no-launch                  # full app build and install to /Applications
```

- Run `swift test` before every commit. All tests must pass.
- Live API tests (`LiveAPITests`) skip unless the provider keys (`ASSEMBLYAI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`) are set in the environment.
- `Mossad.xcodeproj` is generated by XcodeGen from `project.yml`. Do not edit or commit it.
- Set `MOSSAD_ROOT` to a temp folder when running the app by hand so you do not touch real data.

## Conventions

- **Test first.** Write a failing test, then the fix. Pure logic (matchers, the detector, merging, rendering) must stay pure so it can be tested without hardware.
- **Unknown is not false.** Probes return `nil` when they cannot see something (no permission, app not answering). Only return `false` or an empty list when the answer is known. Detection relies on this to avoid ending live calls.
- **Never block the main thread.** AppleScript, Accessibility calls, Core Audio setup, and file trimming can stall. Keep them off the main actor or behind a short timeout.
- **Resumable steps.** Each pipeline step saves `call.json` before the next one starts. Do not add a step that cannot be resumed after a crash.
- **Do not lose audio.** Never delete a call's audio unless the call is shorter than the minimum length or the user skipped it.
- **Secrets.** API keys live only in the Keychain (service `com.dwebber.mossad`). Never log them, write them to files, or put them in code or command arguments.
- **No AI attribution** in commits, PRs, or code comments.
- Match the existing style: small focused files, few comments, comments explain why rather than what.

## Reading meeting notes

If you were asked to act on a meeting, the notes are in `~/Mossad/Meetings/`, one file per call, named `YYYY-MM-DD HHMM - Title.md`.

Each note has YAML front matter (`date`, `start`, `end`, `duration_minutes`, `platform`, `title`, `attendees`, `speakers`, `audio`, `kind` such as "Monthly update" when known, and `tags` such as ["Databricks", "Budget"] when known) followed by `## Summary` (a short overview, then one `###` section per topic), `## Action items` (a checklist; left out for meetings that only share information), `## Decisions` (when any), and `## Transcript`. Transcript lines look like `[HH:MM:SS] Name: text`.

- The note owner's lines use their own name. Unnamed people appear as `Speaker A`, `Speaker B`, and so on, lettered by first appearance.
- The summary and action items are generated. When they disagree with the transcript, trust the transcript.
- Transcripts come from speech recognition and can misspell names and product terms. Check the attendee list for the right spelling.
- To find a meeting, search titles and front matter first, then the transcript text.
